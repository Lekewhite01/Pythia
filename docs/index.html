How it works

Four steps from question to answer.

Every NL request runs through the same grounded pipeline. Schemas are pulled live; the model never sees a column that doesn't exist.

  1. 01

    Pick the relevant tables

    The LLM is shown your full table list and the user's question. It returns only the tables that matter — or an empty list, which we short-circuit as "out of scope."

  2. 02

    Pull live schemas

    SQLAlchemy introspects each chosen table for column names and types, with a raw information_schema fallback when the dialect doesn't expose it.

  3. 03

    Generate SQL + answer + chart

    One LLM call returns four typed fields: query, plain-English answer, suggested chart type, and JSON visualization data. instructor enforces the schema, so the response is always parseable.

  4. 04

    Execute against your DB

    The generated SQL runs via pandas.read_sql and the combined payload — SQL, answer, chart hint, data — is returned to the caller.

Demo

One endpoint. Four useful answers.

POST /convert-nl-to-sql returns everything a frontend needs to render a complete analytics card.

Request
POST /convert-nl-to-sql
Content-Type: application/json

{
  "prompt": "Which marketing channel had the highest ROI in Q1?"
}
Response
{
  "sql_query": "SELECT channel, SUM(revenue)/SUM(spend) AS roi
                FROM marketing_attribution
                WHERE quarter = 'Q1'
                GROUP BY channel ORDER BY roi DESC LIMIT 1",
  "natural_language": "Paid Search had the highest Q1 ROI
                       at 4.7×, driven by branded keywords ...",
  "chart_type": "bar",
  "visualization_data": {
    "labels": ["Paid Search", "Email", "Display", "Social"],
    "values": [4.7, 3.2, 1.9, 1.4]
  }
}
Deploy

Same codebase, three ways to ship.

Local / Uvicorn

cd app
uvicorn main:app --reload \
  --port 8000

Fastest feedback loop. Swagger docs at /docs.

Docker

docker build -t pythia .
docker run -p 8000:8000 \
  --env-file .env pythia

Gunicorn + Uvicorn workers. Production-ready container.

AWS Lambda (SAM)

sam build
sam deploy --guided

HTTP API Gateway in front of a Python 3.10 Lambda. Mangum handles ASGI ↔ Lambda.
